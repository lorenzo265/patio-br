# D-34

**Decisão:** O código do link da transportadora vai no endereço, e não num campo para digitar; o banco guarda só o resumo, e o registro de acesso o esconde

**Motivo:** a transportadora abre o link no celular, direto da mensagem, sem copiar nada; o código é longo (sorteado pela nuvem) e o resumo basta para conferir

**Alternativa descartada:** um código curto para digitar numa página fixa (mais um passo, e curto é fácil de adivinhar)
